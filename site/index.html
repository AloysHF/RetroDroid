RetroDroid 是什么？

RetroDroid 是 AloysHF 模拟器家族的 Android 门户：它自己不模拟任何硬件，而是把家族中的九个模拟器核心以 libretro 核心的形式打包进同一个 APK。

游戏与固件放在设备上固定的文件夹里，打开应用直接选择即可游玩——没有核心下载器，没有联网配置，一切开箱即用。

核心随 APK 一起更新，永远保持一致
系统列表由每个核心的 android.json 档案自动生成
不内置任何游戏或固件，只运行你自己的内容

核心特性

为掌上游戏库而设计的每一个细节

核心全内置

九个模拟器核心全部打包进 APK，没有任何应用内下载或联网校验，装好就能离线畅玩。

固定本机游戏库

游戏放在 /sdcard/RetroDroid 固定目录下，首次启动自动建好目录树，放入文件刷新即见。

即时存档与续玩

五个存档槽位带画面预览；退出游戏时自动保存，下次启动询问是否从上次继续。

强大暂停菜单

游戏内截图、主题/方向/旋转/缩放等画面设置与核心选项，全部集中在暂停菜单里。

文件夹式浏览

子文件夹排在游戏之前、逐层进入，返回手势逐层退出——再大的游戏库也井井有条。

档案即系统

每个核心用一份 android.json 档案描述自己，应用据此生成系统注册表——接入新系统只需核心加档案。

快速上手

三步开始，或者从源码自己构建

📱

安装

1

下载并安装 APK

Releases 提供 arm64-v8a / x86_64 单 ABI 与 universal 版本
2

授予「所有文件访问」权限

首次启动时会自动创建 RetroDroid 目录树
3

选择游戏，开玩

WQX 没有游戏内容，直接选择机型启动固件
📂

放置游戏

1

把游戏放进对应系统目录

/sdcard/RetroDroid/ROMs/<system>/
2

固件放在 BIOS 目录

/sdcard/RetroDroid/BIOS/<system>/
3

刷新游戏列表

文件名区分大小写；光盘游戏把 .cue 与轨道放在一起
🔨

从源码构建

1

准备 Rust + NDK r27+ + JDK 17

rustup target add aarch64-linux-android x86_64-linux-android
2

一条脚本构建全部

./scripts/build-apk.sh assembleRelease
3

或本地调试核心

cp cores/local.env.example cores/local.env
